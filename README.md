# sayoon24

GitHub Pages로 배포할 정적 육아 관리 웹사이트입니다. 배포 주소: https://alcnldsha-a11y.github.io/baby-care-board/

## 개인정보와 저장 방식

배포 파일에는 생년월일 기본값과 개인 기록을 포함하지 않습니다. 입력한 기록은 해당 기기와 브라우저의 localStorage에 저장됩니다. PC와 스마트폰의 기록은 자동 동기화되지 않습니다. 기존 로컬 파일의 기록도 새 사이트로 자동 이전되지 않습니다. 필요하면 화면에서 백업을 내보낸 후 새 사이트에서 직접 불러오세요. 백업 JSON 파일은 공개 저장소에 업로드하지 마세요.

## 최초 배포

사용자 승인과 GitHub 인증 후 새 공개 저장소 baby-care-board를 생성하고 이 폴더의 검토된 파일만 업로드합니다. 기존 저장소가 있으면 덮어쓰지 않습니다.

Settings → Pages → Deploy from a branch → main → /(root) → Save로 설정합니다.

## 수정 후 재배포

이 폴더의 index.html을 수정하고 VS Code 소스 제어에서 변경 내용을 확인하여 커밋하고 푸시하세요. 최초 배포 설정 후 main 브랜치에 푸시하면 자동 재배포됩니다.

터미널에서는 이 폴더에서 다음을 실행합니다.

```powershell
git add -- index.html README.md .gitignore .nojekyll
git diff --cached
git commit -m "Update care board"
git push origin main
```

.gitignore는 검토한 배포 파일만 허용합니다. 새 파일을 추가할 때 개인정보를 점검하고 허용 목록을 수정하세요. 인증 토큰이나 비밀번호를 코드에 저장하지 마세요.
## 사진·건강 기록

상단의 사진·건강 기록에서 사진 업로드, 앨범 검색, 보호자 수동 평가, 전후 비교, 성장 측정 기록·그래프, 진료용 요약 인쇄/PDF를 사용할 수 있습니다. 사진·측정값은 IndexedDB에 저장됩니다. 사진 포함 전체 ZIP 백업을 정기적으로 내려받으세요. 기존 JSON 백업은 육아 기록 전용으로 유지되며 사진을 포함하지 않습니다.

AI 자동분석은 미연결 상태입니다. 사진을 외부로 전송하지 않습니다. 연결 후보·요금·개인정보 처리·승인 필요 사항은 [AI 연결 검토](AI-INTEGRATION.md)를 참고하세요.

배포 자산: index.html, health.css, health.js, health-data.js. 외부 스크립트나 CDN 라이브러리를 사용하지 않습니다. 모든 자산 경로는 프로젝트 하위 경로에 대응하는 상대 경로입니다. 실제 사진·백업·비밀키·테스트 자료는 커밋하지 마세요.

## 모바일 사용

스마트폰에서는 하단의 오늘·체크·기록·사진·월령 메뉴로 이동합니다. PC에서는 기존 상단 메뉴를 사용합니다. 사진 앨범은 2열 썸네일이며 사진을 누르면 잘리지 않는 상세 사진과 메모·보호자 평가·수정·삭제 버튼을 볼 수 있습니다. 검색·필터는 접어도 조건이 유지되며 활성 개수와 초기화 버튼을 제공합니다. 사진은 40장씩 더 볼 수 있습니다.

JPEG의 촬영 메타데이터를 읽을 수 있으면 촬영일을 자동 적용합니다. 메타데이터가 없거나 지원하지 않는 형식이면 날짜를 직접 선택하세요. 날짜를 직접 바꾸면 선택한 사진 전체에 적용합니다. 업로드 후 앨범으로 이동하며 동일한 변환 사진이 있으면 중복 저장을 확인합니다. 원본 메타데이터는 저장 사진에 복사하지 않습니다.

빠른 기록에서 자주 쓰는 종류를 선택할 수 있고 육아 기록 탭에서 개별 기록을 수정할 수 있습니다. 연속 누르기로 인한 중복 저장은 제한합니다. 기존 localStorage·IndexedDB 이름과 저장 데이터 형식은 변경하지 않았습니다. 썸네일은 표시용으로 메모리에서만 생성하므로 기존 ZIP·JSON 형식에 영향을 주지 않습니다. 추가 배포 자산은 mobile.css와 mobile.js입니다. AI 연결 상태는 변경하지 않았습니다.

실제 아이폰·안드로이드에서는 키보드 표시 중 저장 버튼 접근, 화면 회전, 하단 안전 영역, 사진첩·카메라 권한을 확인하세요. 사이트 데이터 삭제나 저장소 초기화는 하지 마세요.

## 한 손으로 기록하기

상단의 출생일·현재 월령·수유 방식 요약을 누르면 상세 설정을 펼칠 수 있습니다. 기존 생년월일은 실제 출생일로 유지하며 자동으로 바꾸지 않습니다. 출생 예정일은 별도의 선택 항목 `dueDate`로 저장합니다. 실제 출생일이 없거나 기존 등록일이 미래이면 출산 준비를 우선 표시하고, 실제 출생일이 입력되면 육아 루틴을 표시합니다. 예정일이 지났다고 자동으로 출생 처리하지 않습니다. 날짜 변경은 보호자가 직접 수행하며 기존 날짜 변경 전 확인합니다.

오늘 화면 맨 위의 모유·유축·분유·기저귀·수면 버튼은 같은 화면에서 입력창을 엽니다. 직접 모유는 왼쪽·오른쪽 수유 시간(분), 유축·분유는 각각 섭취량(mL)을 기록합니다. 혼합 수유도 종류별 이벤트로 저장하며 분과 mL를 합산하지 않습니다. 기존 직접 모유의 `amount`는 단위를 추정하지 않고 ‘기존 입력값 (단위 미지정)’으로 보존합니다. 새 직접 모유 기록에만 선택적인 `nursing: {left, right}` 분 필드를 추가합니다. 기존 이벤트·사진·메모를 재작성하거나 저장소를 마이그레이션하지 않습니다.

새 JSON·전체 ZIP은 예정일과 좌·우 수유 시간도 백업·복원합니다. 기존 형식 백업도 계속 불러올 수 있습니다. 새 선택 필드는 업데이트 이전 앱에서는 보존되지 않을 수 있으므로 최신 사이트에서 복원하세요. 복원은 확인 후 백업 전체 내용으로 교체하는 기존 방식입니다.

사진 업로드의 기본 화면은 사진첩·카메라 선택, 카테고리, 촬영일, 저장으로 구성합니다. 기록일은 기기 기준 오늘이 기본값이며 증상 발생일·메모·측정 연결·기록일 수정은 ‘상세 정보 추가’에 있습니다. 원본 JPEG 촬영일이 있으면 자동 사용하며 수동 날짜 수정도 가능합니다. 추가 자산은 care-ui.js와 care-ui.css입니다. AI는 계속 미연결입니다.
